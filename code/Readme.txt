# README

This repository contains the R source code and corresponding results used in the manuscript.

The files are organized according to the tables and figures in the manuscript. For each table or figure, the corresponding source code and output results are provided and clearly named.

All analyses were conducted in R. After installing the required R packages, the .R scripts can be run directly to reproduce the corresponding results.

For some tables, the final presentation format requires further organization or summarization based on the raw program outputs.
